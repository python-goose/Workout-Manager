Exercise

Создаёт объект упражнения, хранит информацию об упражнении. Например, упражнение — это отжимания или подтягивания на турнике.

new Exercise(data: Object)
Parameters
data (Object) сырые данные упражнения
Name Description
data.id Number порядковый номер упражнения (уникальный)
data.name String название упражнения
data.reps Number количество повторений
data.weight Number дополнительный вес
data.time Number время выполнения всех повторений
data.photo_small String ссылка на фото, 45×45px
data.photo_large String ссылка на фото, 485×365px
Properties
sets (Number) : количество выполненных подходов, изначально 0; меняется через changeSets() в WorkoutSession
photoSmall (String) : фото 45×45px; если photo_small не передан, используется заглушка https://placehold.co/45x45
photoLarge (String) : фото 485×365px; если photo_large не передан, используется заглушка https://placehold.co/485x365

CompletedExercise

Снимок выполненного упражнения. Наследует Exercise и копирует в себя все его поля через Object.assign — так получается независимая копия (не ссылка), зафиксированная на момент выполнения. Это нужно, потому что одно и то же упражнение пользователь может выполнить несколько раз за тренировку с разными повторениями и весом — каждый подход должен хранить свои собственные показатели, а не общую ссылку на исходное упражнение.

dateEnd (Date) : дата и время выполнения подхода, фиксируется в момент создания
complexityAssessment (Number) : оценка сложности подхода от 1 до 100, изначально 1

WorkoutSession

Центральное хранилище состояния приложения (что-то вроде store) — держит список всех тренировок, текущую активную тренировку и упражнение, текущий вид отображения (таблица/список/карточка), а также лог выполненной тренировки (completedWorkout). Всё управление данными тренировки идёт через методы этого класса.

▸ changeSets(exerciseId, delta)

Увеличивает или уменьшает количество выполненных сетов у упражнения. При первом сете (delta === 1, было 0) автоматически переключает активное упражнение на следующее — так одно и то же упражнение можно выполнить несколько раз, не застревая на нём в интерфейсе. Синхронно ведёт лог в completedWorkout: при +1 добавляет запись о выполненном подходе, при -1 удаляет последнюю такую запись. Не даёт уйти в минус — если сетов 0, а delta === -1, ничего не делает.

changeSets(exerciseId: Number, delta: Number)
Parameters
exerciseId (Number) id упражнения
delta (Number) на сколько изменить количество сетов (1 или -1)

Timer

Таймер тренировки с тремя фазами — подготовка, тренировка, перетренированность (превышение планового времени). Работает через setInterval с шагом в секунду и уведомляет внешний код о каждом тике через callback onTick, который нужно подключить снаружи (instance.onTick = function(t){...}).

new Timer(prepSeconds: Number, trainSeconds: Number, overtimeFactor: Number)
Parameters
prepSeconds (Number) время подготовки, сек
trainSeconds (Number) время тренировки, сек
overtimeFactor (Number) коэффициент допустимого перетренировки (доля от trainSeconds, например 0.2 = 20% сверх тренировочного времени)
Properties
prepSeconds (Number) : время подготовки, сек
trainSeconds (Number) : время тренировки, сек
overtimeFactor (Number) : коэффициент перетренировки
totalSeconds (Number) : общая длительность таймера (prep + train + overtime), сек
currentSeconds (Number) : сколько секунд уже прошло с начала отсчёта
intervalId ((Number | null)) : id таймера setInterval; null, если таймер не запущен
onTick ((Function | null)) : callback, вызывается каждую секунду с this в качестве аргумента; null, пока не подключён снаружи
